# GNOME Extension i18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add gettext internationalization to the GNOME Shell extension, supporting English (source) and Simplified Chinese.

**Architecture:** Standard GNOME Shell extension gettext pattern — `po/` directory with `.pot` template and `.po` files, Makefile-driven build with `xgettext`/`msgfmt`, output to `locale/<lang>/LC_MESSAGES/`. GNOME Shell 45+ auto-binds the gettext domain from metadata.json.

**Tech Stack:** GNU gettext (xgettext, msgfmt, msgmerge), Make, JavaScript gettext `_()` calls (already in place).

**Design Spec:** `docs/superpowers/specs/2026-05-27-gnome-i18n-design.md`

### Task 5: Create Makefile

**Files:**
- Create: `KeyStats.GNOME/keystats@debugtheworldbot.github.io/Makefile`

- [ ] **Step 1: Write Makefile**

```makefile
# KeyStats GNOME Shell Extension — i18n Build
# Usage:
#   make        — build all (.pot → .po → .mo)
#   make pot    — extract strings from source into .pot template
#   make po     — update .po files with new strings from .pot
#   make mo     — compile .po → .mo
#   make install — install locale to GNOME Shell extension dir
#   make clean  — remove generated files

EXTENSION_DIR := $(shell pwd)
PO_DIR        := $(EXTENSION_DIR)/po
LOCALE_DIR    := $(EXTENSION_DIR)/locale
DOMAIN        := keystats
POT_FILE      := $(PO_DIR)/$(DOMAIN).pot
SOURCES       := extension.js prefs.js
INSTALL_DIR   := $(HOME)/.local/share/gnome-shell/extensions/keystats@debugtheworldbot.github.io/locale

LANGS := zh_CN

.PHONY: all pot po mo install clean

all: pot po mo

pot:
	@mkdir -p $(PO_DIR)
	xgettext \
		--language=JavaScript \
		--keyword=_ \
		--output=$(POT_FILE) \
		--package-name=$(DOMAIN) \
		--package-version=1 \
		--copyright-holder="KeyStats Contributors" \
		--msgid-bugs-address="https://github.com/debugtheworldbot/KeyStats/issues" \
		--from-code=UTF-8 \
		$(SOURCES)
	@echo "Generated $(POT_FILE)"

po: $(addprefix po-update-,$(LANGS))

po-update-%: $(POT_FILE)
	msgmerge --update --backup=none $(PO_DIR)/$*.po $(POT_FILE)
	@echo "Updated $(PO_DIR)/$*.po"

mo: $(addprefix mo-,$(LANGS))

mo-%: $(PO_DIR)/%.po
	@mkdir -p $(LOCALE_DIR)/$*/LC_MESSAGES
	msgfmt --check --output-file=$(LOCALE_DIR)/$*/LC_MESSAGES/$(DOMAIN).mo $(PO_DIR)/$*.po
	@echo "Compiled $(LOCALE_DIR)/$*/LC_MESSAGES/$(DOMAIN).mo"

install: mo
	@mkdir -p $(INSTALL_DIR)
	cp -r $(LOCALE_DIR)/* $(INSTALL_DIR)/
	@echo "Installed locale to $(INSTALL_DIR)"

clean:
	rm -f $(PO_DIR)/*.po~
	rm -f $(POT_FILE)
	rm -rf $(LOCALE_DIR)
	@echo "Cleaned generated i18n files"
```
